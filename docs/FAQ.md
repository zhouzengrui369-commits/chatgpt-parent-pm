# FAQ

## Is this an autonomous agent platform?

No. It is a repository-native governance and handoff framework.

## Must the local agent be Codex or MiniMax Code?

No. Local roles are capability-based.

## Can a local agent fix code?

Only when a Goal explicitly delegates source authority. The default separation keeps source changes in GitHub under the remote Parent PM.

## Does CI PASS mean the product is done?

No. Runtime, product experience, customer value, and delivery identity are separate gates.

## Why exact SHA instead of only a branch name?

Branches move. A SHA identifies the candidate that was actually deployed and tested.

## Can this be used in private repositories?

Yes. Do not publish private evidence or credentials into the public framework repository.
