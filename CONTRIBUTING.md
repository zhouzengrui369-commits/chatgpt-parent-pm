# Contributing

Contributions are welcome when they improve reproducibility, role clarity, safety, or adoption across different project types.

## Principles

- Keep the core agent- and project-portable.
- Do not embed private repository names, credentials, local absolute paths, or customer data.
- Separate normative rules from examples.
- Add tests for validator or schema changes.
- Do not weaken exact-SHA identity, evidence, owner approval, or branch-safety gates without an explicit design discussion.

## Pull requests

Include:

- problem and intended user value
- changed contracts or invariants
- verification commands and observed results
- migration impact
- what was not tested

All contributions are licensed under Apache-2.0.
