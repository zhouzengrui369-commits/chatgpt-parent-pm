# Goal-Driven Development

A Goal is a bounded, evidence-bearing product increment or governance prerequisite.

Every Goal defines:

- `goal_id`
- user or system outcome
- product weight, including `0%` for governance-only work
- input repository, branch, and SHA
- allowed and forbidden paths
- acceptance criteria
- required tests and evidence
- owner-locked decisions
- terminal status rules

A task list is not a Goal. A Goal closes only when the required acceptance gates close.
