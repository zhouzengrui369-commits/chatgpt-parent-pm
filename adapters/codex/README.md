# Codex Local Adapter

Codex can be assigned one or both local roles:

- exact-SHA deployment runner
- real-operation test and product-experience auditor

The contract, not the product name, determines authority. In the default model Codex does not modify source or push commits during acceptance testing.

Recommended receipt fields:

- repository / branch / SHA identity
- build and launch result
- actual browser or desktop steps
- screenshots or annotations
- accessibility and recovery findings
- focused retest verdict
